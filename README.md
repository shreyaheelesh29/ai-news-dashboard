# Whatever I'm Working On

A small static page for publishing current work, notes, and experiments.

## Files

- `index.html` is the page markup.
- `styles.css` contains the responsive layout and visual styling.
- `script.js` keeps the displayed update date current.

## Run locally

Open `index.html` in a browser. No build step is required.

## Publish

This project is ready for GitHub Pages from the repository root.
